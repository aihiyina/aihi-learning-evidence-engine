# WHYWHY 0.1 · AIHI 질문 연구소

> **CURRENT: 로컬 체험용 학습 순환 MVP. 실제 아동 또는 학교에서의 사용 금지.**  
> **PLANNED: 아동 보호/교사 인증/동의 검증 완료 후 제한된 POC.**

WHYWHY는 기존 AIHI 꿈나무AI의 **질문 중심 AI Literacy 수업 모듈**이다. 교육 철학을 바꿔 새 제품을 발명한 것이 아니라, AIHI의 기존 기준문서에 있던 첫 생각 → 질문 → 근거 확인 → 생각 수정 → 자기 설명 → 교사 판단을 하나의 실행 가능한 학습 장면으로 만들었다.

## 실행하기

Python 3.10+가 필요하다.

**Windows:** `start_windows.bat` 두 번 클릭 후 `http://127.0.0.1:8765` 접속.

**macOS / Linux:**

```bash
cd WHYWHY_v0.1
python3 -m pip install -r requirements.txt
python3 -m uvicorn whywhy.app:app --host 127.0.0.1 --port 8765
# 다른 브라우저 창에서 http://127.0.0.1:8765
```

**자동 테스트:**

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m pytest -q
```

## 지금 실제 작동하는 것

- 초등 3~4학년 대상 첫 AI 리터러시 40분 수업 시나리오.
- 먼저 생각을 남겨야 다음 질문으로 넘어갈 수 있는 **순서 기반 질문 제어 엔진**.
- 첫 생각 / 어린이가 만든 질문 / 근거 확인 / 생각 수정 / 자기 설명을 개별 학습 이벤트로 저장.
- 증거를 읽기만 하는 교사 검토 화면. 정답 점수나 성향 자동 판정 없음.
- 교사의 승인·수정요청·반려 기록, 학생별 체험 기록 완전 삭제, JSON 내보내기.
- 이메일 / 일부 휴대전화번호 / 주민등록번호 **형식** 차단 (제한적 데모 검사로, 안전성 보증 불가).
- 개발용 SQLite 데이터 저장과 FastAPI API, 반응형 웹 UI, 자동 단위·API 테스트.

## 실제 작동하지 않는 것 (중요)

- **생성형 AI 모델 연동 없음.** 질문 프롬프트는 결정론적 수업 시나리오로 고정되어 있다.
- 실시간 최신 교육과정 자동 수집 없음. `skills/education-radar`는 앞으로 적용할 조사 규칙이다.
- 학년별 과목 전체, 개별 학습 적응, 실시간 음성, 이미지 입력 없음.
- 교사 인증·권한 분리, 보호자 동의, 접근 로그, 데이터 암호화, 원격 안전관리 없음.
- **따라서 실제 학생 개인정보를 입력하거나 서비스를 외부 인터넷에 노출해서는 안 된다.**
- 일반 학교 배포나 법적 적합성 검증이 끝난 제품이 아니다.

## 철학과 설계 기준

1. 질문 자체를 학년이라는 이유만으로 막지 않는다. 표현 난이도와 설명 방식, 안전 규칙을 연령에 맞춰 조절한다.
2. AI는 아이의 정답을 대신 작성하지 않는다. 질문을 열어 주고 반박·수정 기회를 제공한다.
3. AI가 학생의 성적·능력·성격을 자동 판정하지 않는다.
4. 학습 장면(event)과 그 장면으로부터 관찰 가능한 근거(evidence)를 구분한다.
5. 교사가 최종 교육적 판단권을 가진다.
6. 모델, 도구, 정책이 바뀌어도 학습 이벤트 스키마를 유지한다.
7. 모델 또는 외부 스킬 변경 시 재검증 없이는 실증용으로 승격하지 않는다.

## 기존 AIHI 기술 기반과의 관계

- `apps/dreamtree`: 학생 경험의 기존 책임 경계. WHYWHY는 하위 모듈 후보.
- `packages/learning-engine`: 질문 제어 및 학습 이벤트 처리의 향후 공유 경계.
- `packages/safety`: 아동 안전 정책의 향후 공유 경계.
- 이번 ZIP은 검증 가능한 **독립 실행 베이스**이며, GitHub 원본 저장소에 병합하거나 배포한 상태가 아니다.
- 라이선스·IP 귀속은 원본 AIHI 기준을 존중하며 새 라이선스를 임의로 선언하지 않는다.

상세 설계와 안전: `docs/ARCHITECTURE.md`, `docs/CLASSROOM_LESSON.md`, `docs/SAFETY_AND_GATES.md`, `docs/SOURCES.md`.
